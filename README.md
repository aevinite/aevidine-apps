# Aevidine apps

Installers for **Aevidine**, the restaurant system by [Aevinite](https://aevinite.com): Mac, Windows and Linux.
Get the right one for your device at **https://aevidine.aevinite.com/download/**. Android is on Google Play.

This repository holds only the finished installers (in Releases) and `latest.json`, the file every installed app reads
to offer "Update now". The app itself is the Aevidine website; nothing here contains your restaurant's data.
